## Run with Node 22

```sh
mkdir -p out
MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies the bundled 1024 by 1024 PNG byte for byte. Set `MAKEFUN_OUTPUT_DIR` to choose the destination directory; it defaults to `/output`.
